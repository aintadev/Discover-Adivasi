## What is This?

Discover Adivasi is a brilliant parody of **ancestry website**  where you can build **ridiculous family trees with made-up ethnicities** and generate outrageously **fake historical records** for any name you search.

### Features

### Family Tree Builder 🏗️

- Add unlimited family members with custom names, ethnicities, and details
- Choose from hilarious ethnicity options like "Butter Chicken Connoisseur" or "Coconut Crusader"
- Save your masterpiece to browser storage
- Reset and start fresh whenever you want

### Historical Records Search 🔍

- Type any name to generate a completely fake historical profile
- Get detailed descriptions with age, occupation, and absurd achievements
- Discover 20+ pre-made characters with wild backstories
- Each search returns random hilarious results

### Visual Design 🎨

- Bright, colorful comic-style interface
- Smooth animations and gradients
- Responsive design works on desktop and mobile
- Comic fonts and playful styling

### How to Play

1. Build Your Family Tree:
   - Fill in family member details (name, ethnicity, backstory)
   - Click "Add to Family Tree" to see them appear
   - Save your tree when you're done
2. Search Historical Records:
   - Type any name in the search bar
   - Get a randomly generated fake historical profile
   - Enjoy the completely made-up backstory and achievements
3. Save & Reset:
   - Save your family tree to keep it forever
   - Reset to start a new hilarious family lineage

## Technical Stuff

- Frontend: Pure HTML, CSS, JavaScript
- Storage: Browser localStorage for saving family trees
- Data: JSON-based character database
- Design: Responsive with CSS Grid and Flexbox
- No frameworks, no dependencies, just fun!
